# AI Training Advanced Features Plan
**Date:** January 6, 2026 at 23:36 PM IST

## Current State
AI Training has 4 tabs:
1. Identity - Basic user info
2. Personality - Zeni's persona
3. Knowledge - Facts/rules
4. Habits - Work patterns

## Advanced Features to Add

### 1. Training Progress Dashboard
- **AI Maturity Score** (0-100%) based on knowledge entries
- **Learning Timeline** - Visual chart of training over time
- **Training Recommendations** - "Add more about X" suggestions

### 2. Quick Personality Templates
Pre-built personas user can activate:
- **Professional Butler** - Formal, respectful (Jeeves-style)
- **Enthusiastic Coach** - Motivational, energetic  
- **Calm Mentor** - Wise, patient, contemplative
- **Playful Friend** - Casual, fun, supportive
- **Custom** - User-defined (current approach)

### 3. Context-Aware Learning
- **Session Pattern Detection** - Auto-learn from behavior
- **Auto-Tag Knowledge** - Smart categorization
- **Conflict Detection** - Warn when adding contradictory info

### 4. Training History & Analytics
- **Recent Changes** - What was taught recently
- **Most Used Patterns** - Which knowledge gets referenced most
- **Effectiveness Metrics** - How well AI applies training

### 5. Advanced Knowledge Types
Current: fact, rule, preference
Add:
- **Triggers** - "When X happens, do Y"
- **Goals** - Long-term objectives
- **Avoid** - Things to never suggest

### 6. Import/Export Training Profile
- **Export to JSON** - Backup training data
- **Import Profile** - Load from file
- **Share Templates** - Community profiles

## Implementation Priority
1. ✅ Templates (Quick win, high impact)
2. Training Progress (Visual feedback)
3. Advanced Knowledge Types
4. History & Analytics
5. Import/Export

## Design Updates
- Keep spacious, clean layout
- Add progress rings/charts
- Template cards with preview
- Smooth animations for transitions
- Proper spacing (24px+ between sections)
