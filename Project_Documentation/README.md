## 🔄 Maintenance

### When Creating New Documents:
1. **Always include date:** `YYYY-MM-DD_` prefix
2. **Use descriptive names:** Clear, searchable titles
3. **Update this index:** Add entry in appropriate section
4. **Archive old versions:** Move superseded docs to Archive/

### Document Lifecycle:
- **Active:** Current, relevant documentation
- **Superseded:** Moved to Archive/ with `[SUPERSEDED]` prefix
- **Historical:** Kept in Archive/ for reference
