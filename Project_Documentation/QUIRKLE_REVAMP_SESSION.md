## 🎯 DESIGN PRINCIPLES FROM INSPIRATION

### Colors & Backgrounds
- Dark flat backgrounds (#2B2B2B range)
- NO heavy glassmorphism/blur
- NO complex gradients
- Subtle borders (1px, low opacity)
- Minimal shadows

### Spacing
- Compact, efficient (not overly spacious)
- Functional padding (12-16px, not 24px+)
- Clean gaps between elements

### Typography
- Clean, readable sizes (14-16px base)
- Not overly large titles
- Good contrast, simple hierarchy

### Icons & Elements
- Small, subtle icons (16-20px)
- Flat buttons with simple hover states
- Accent color (purple/fuchsia) used sparingly
- Checkboxes/clean UI elements

### Overall Feel
- Modern, professional, clean
- Like Claude, ChatGPT, Linear
- Functional over decorative
- Fast, responsive feeling
