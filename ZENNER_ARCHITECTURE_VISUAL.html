📖 What is Zenner?

Zenner is a next-generation productivity timer that combines the proven Pomodoro Technique with AI-powered coaching, binaural beats, and real-time analytics. It's like having a personal productivity coach that learns from your habits.

⏱️ Smart Timer

15+ preset timer modes from 15min ultrasprint to 90min marathons, including psychedelic focus modes.

🧠 AI Coach (Zeni)

Powered by Gemini, OpenAI, Claude, or local Ollama. Learns your patterns, suggests breaks, analyzes productivity.

📊 Analytics

Real-time session tracking, streak tracking, heatmaps, and productivity insights.

🎵 Binaural Beats

Frequency generator with preset modes: focus (40Hz), relax (7Hz), sleep (2Hz), and more.

🗄️ Database Layer

SQLite Tables:

zenner.db
├── sessions           ← All timer sessions
├── session_notes      ← Per-session journal entries
├── journal_entries    ← Daily journal  
├── chat_sessions      ← AI conversation history
├── training_data      ← User preferences & training
└── analytics          ← Aggregated stats

Persistence Strategy:
• All data stored locally in SQLite
• No cloud dependency (privacy-first)
• Optional Supabase sync for multi-device
• Automatic backups to user's Documents folder

1️⃣ AI Chat Flow (Production CORS Fix)

sequenceDiagram participant UI as ZeniView participant Service as CoachService participant Wrapper as safeFetch() participant Tauri as Tauri HTTP Plugin participant API as Gemini/OpenAI API UI->>Service: chat("How can I focus better?") Service->>Wrapper: fetch(API_URL, {body, headers}) alt Development Mode Wrapper->>API: Native browser fetch() Note over Wrapper: No CORS issues in dev else Production Mode Wrapper->>Tauri: Tauri HTTP fetch() Tauri->>API: Rust HTTP client Note over Tauri: Bypasses CORS restrictions end API-->>Tauri: AI Response Tauri-->>Wrapper: Response Wrapper-->>Service: Parsed JSON Service-->>UI: Display message

🔧 Key Fix: The safeFetch() wrapper conditionally uses Tauri's HTTP client in production to bypass browser CORS restrictions while maintaining normal fetch() behavior in development.
